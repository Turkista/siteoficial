# assets/hero/

Coloque aqui a foto principal do hero da Home.

| Arquivo esperado    | Usado em      | Proporção sugerida |
|---------------------|----------------|---------------------|
| `hero-praia.webp`   | index.html (hero) | paisagem, 16:9 ou mais larga, boa leitura na metade direita da imagem (o texto fica à esquerda) |

Até o arquivo existir, o `index.html` usa um gradiente CSS como placeholder e some automaticamente para a foto assim que o arquivo `hero-praia.webp` for colocado nesta pasta — não precisa mexer no código.

**Sobre o formato WebP:** todo o projeto usa `.webp` em vez de `.jpg`/`.png` — mesma qualidade visual, mas ~90-95% mais leve, o que ajuda diretamente o Core Web Vitals (LCP). Pode enviar a foto original em qualquer formato (JPG, PNG, HEIC do celular) — a conversão para `.webp` com este nome exato é feita antes de a foto entrar nesta pasta.
