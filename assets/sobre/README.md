# assets/sobre/

Colagem de 3 fotos de bastidores usada na Home, na seção "Do ateliê da minha mãe para o seu movimento" (preview que linka para Sobre a Marca).

| Arquivo esperado        | Posição na colagem              |
|---------------------------|-----------------------------------|
| `bastidores-1.webp`       | Foto grande, à esquerda (ocupa as 2 linhas) |
| `bastidores-2.webp`       | Foto pequena, superior direita  |
| `bastidores-3.webp`       | Foto pequena, inferior direita  |

Estas mesmas fotos (ou variações) também podem ser reaproveitadas na página `sobre-a-marca.html`, que já tem placeholders equivalentes aguardando a sessão fotográfica (ver `Turkista_Status_Implementacao.md`).

**Sobre o formato WebP:** todo o projeto usa `.webp` em vez de `.jpg`/`.png` (mesma qualidade, ~90-95% mais leve). Pode enviar a foto original em qualquer formato — a conversão para `.webp` é feita antes de a foto entrar nesta pasta.
