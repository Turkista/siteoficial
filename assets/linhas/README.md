# assets/linhas/

Fotos dos 3 cards de linha na Home (seção "Três linhas, um mesmo padrão de acabamento").

| Arquivo esperado   | Linha    |
|---------------------|----------|
| `praia.webp`         | Moda Praia |
| `surf.webp`           | Surf       |
| `turk-fit.webp`       | Turk Fit   |

Proporção 3:4 (retrato), still-life ou uso real — o card já aplica um degradê escuro por cima para o texto branco ficar legível. Ao colocar o arquivo com o nome exato, ele substitui o gradiente placeholder automaticamente.

**Sobre o formato WebP:** todo o projeto usa `.webp` em vez de `.jpg`/`.png` (mesma qualidade, ~90-95% mais leve). Pode enviar a foto original em qualquer formato — a conversão para `.webp` é feita antes de a foto entrar nesta pasta.
