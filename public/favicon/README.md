# public/favicon/

Coloque aqui os arquivos de favicon (favicon.ico, apple-touch-icon.png, etc.) quando o ícone final da marca estiver definido.

**Nota:** favicons são a única exceção à política de `.webp` do projeto — `favicon.ico` e `apple-touch-icon.png` precisam manter seus formatos originais porque navegadores e sistemas operacionais (em especial iOS) não têm suporte garantido a WebP para ícones.
