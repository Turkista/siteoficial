# public/favicon/

Ícone provisório: monograma "T" em Rosa Turkista (`#F279C8`) sobre Preto Grafite (`#0C1014`).

- `favicon.svg` — ícone vetorial (abas de navegador modernas)
- `apple-touch-icon.png` — 180×180, quadrado (o iOS aplica a própria máscara)
- `icon-192.png`, `icon-512.png` — para manifesto/Android
- `/favicon.ico` fica na **raiz** do projeto (16, 32 e 48 px): navegadores e o Google o procuram lá.

Para usar o logo oficial, substitua estes arquivos mantendo os mesmos nomes. O Google pede ícone em múltiplo de 48 px, com formato quadrado, e o mostra nos resultados de busca do celular.

Favicons são a única exceção à política de `.webp` do projeto.
